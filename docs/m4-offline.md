# M4 应用范围断网与原生 Excel 复验

本项在应用 0.3.0、macOS 27.0.1 / arm64、CPython 3.12.14、Streamlit 1.66.0 的新 `.venv-m4-clean` 中完成。记录日期为 2026-10-24（Asia/Singapore）。**已验证的是应用范围的外网隔离流程；整台 Mac 没有物理断网，也没有生成 pcap 抓包。** 本项成功不单独代表 M4 全部完成或 v1 已发布。

## 隔离方式与证明范围

普通产品入口仍是 README 中绑定 `127.0.0.1:8501` 的 Streamlit 启动命令。本次验收另用端口 8502 和两层测试夹具：

1. [loopback-only.sb](../scripts/loopback-only.sb) 由 macOS `sandbox-exec` 对服务进程施加网络策略，只允许回环网络。IPv4 与 IPv6 的非回环 TEST-NET 地址连接均返回操作系统权限拒绝 `EPERM`（errno 1），而非依赖超时、目标不可达或 DNS 失败来声称阻断成功。
2. [acceptance_offline.py](../scripts/acceptance_offline.py) 在本地响应增加测试专用 CSP，限制页面子资源和连接到本地来源，字体、图片等允许本地数据或 blob。独立正向控制页故意引用外部图片，浏览器报告 `img-src` 策略阻断。该控制不携带任何业务数据。

服务端 Python audit hook 记录 socket/DNS 的端点分类；测试中间件记录入站路径的类别、协议及响应码；CSP 报告仅记录指令、是否外部来源及是否为正向控制。它们不记录上传内容、文件名、查询字符串、原始路径或请求正文。网络事件日志属于本次验收夹具，不是应用默认新增的业务日志。

操作系统策略约束服务进程的外联；CSP 约束这张页面的资源及连接。Mac 上其他程序、浏览器其他页面和浏览器自身服务没有被本夹具断网。Python audit hook 的“未观测到调用”也不是完整系统调用追踪；没有逐包网络捕获。这里不声称已验证整机所有流量、DNS 服务、浏览器遥测或其他进程均为零。

`sandbox-exec` 是本次 Mac 验收工具，已被系统标记为弃用；它不是产品依赖，不承诺其他系统可运行此夹具。测试 CSP 与中间件只用于验收，正常页面启动不依赖它们。夹具使用锁定 Streamlit 版本的内部挂载点，升级框架后必须重新验证。

## 重复验证方法

在安装完成的项目根目录启动隔离测试入口：

```sh
/usr/bin/sandbox-exec -f scripts/loopback-only.sb \
  .venv-m4-clean/bin/python scripts/acceptance_offline.py
```

先打开 `http://127.0.0.1:8502/_m4/probe` 检查浏览器控制页，再访问 `http://127.0.0.1:8502` 实际上传两份样例，完成确认、核对与报告下载。服务启动时自动执行 OS 拒绝控制；如果返回超时或普通路由错误，夹具会失败退出，不能作为隔离通过证据。

夹具会向 `docs/m4-network-events.jsonl` **追加**事件。重复验证前应先保留本次证据，另行整理新一轮记录；不能把多次运行的累计数字当作单次成绩，也不要覆盖当前已交付的报告与截图。端口 8502 仅供测试，若占用，先确认是本项目服务后再停止。正常使用继续按 README 从项目目录启动 8501。

检查新报告时应独立从输入文件复算，再调用 `audit_xlsx` 逐项回读，并记录实际文件哈希、运行标识、页签与行数。仅看到 HTTP 200、下载按钮或文件存在，均不足以证明报告内容通过审计。

## 原生 Excel 观察

上述同一报告在 **Microsoft Excel for Mac 16.114（build 16.114.26101123）** 实际打开；未出现修复、链接更新或宏提示。观察到五张工作表，A002 订单 `50.00`、收款 `49.00`、差额 `-1.00` / `-100` 分；A007 为真实零，缺失一侧保留空白。源行账本能定位 A002 两侧原行及共同 `result_id`，A005 的重复与关联隔离问题可见。

Excel 自动保存关闭，未编辑或保存文件。关闭后的文件 SHA-256 与上述下载值相同。证据见 [m4-excel.json](m4-excel.json)、[业务结果截图](m4-excel-results.png) 和[源行账本截图](m4-excel-ledger.png)。

兼容结论只覆盖本机 Excel 版本与这一份虚构混合 CSV/XLSX 报告。未运行 Windows Excel、WPS 或 LibreOffice，不能由本次打开成功推导其行为。原生软件观察也不能替代全部公式注入、坏文件及逐单元格回读测试；这些另见 [日志与导出安全复验](m4-log-security.md)。
