## 旧操作与旧报告失效

审查中发现并修复了一个 P1 并发问题：快速重跑时，旧读入、核对或导出可能晚于新输入完成，使旧结果恢复，或让旧报告字节配上新文件名。现在 [ui_state.py](../sheetcheck/ui_state.py) 使用会话内锁、版本号和源读取标识，只允许当前操作提交结果；旧操作成功或失败都不能清除或覆盖新状态。`report_for_run` 在同一次锁内核验当前结果身份和报告，旧下载请求不能获取新运行的字节。

22 项测试通过事件控制操作顺序，覆盖旧读入/校验/核对/导出的成功与失败、处理途中重置、相同输入重复操作及旧下载身份，避免仅依赖时序偶然的压力测试。延迟下载回调会在单独线程执行，因此需要上述身份核验，不能只隐藏页面按钮。[官方 download_button 文档](https://docs.streamlit.io/develop/api-reference/widgets/st.download_button)

这里的“失效”是禁止旧操作提交结果，不承诺立即停止已经开始的 CPU 计算。已经交给浏览器的下载字节不能撤回；同步处理仍无自动墙钟超时。

## 实际浏览器流程和下载回读

最终代码在本机 `http://127.0.0.1:8501` 完成以下操作：加载虚构样例 → 手动勾选同币种、同期间确认 → 开始核对 → 搜索 A002 → 查看来源详情 → 生成报告 → 点击并取得下载文件。A002 的订单和收款来源均显示 CSV 原始行 3，差额为 -1.00。

当前搜索为 A002 时，下载仍包含完整运行。实际取得的 XLSX 使用源 CSV 与报告运行元数据重新复算后通过 `audit_xlsx`，五页数据行数如下，不含表头：

实际文件路径、字节数、SHA-256、运行编号、筛选状态和回读结果见 [浏览器下载证据](m3-browser-check.json)。证据记录所指向的两份本地下载文件均已核查存在、长度与 SHA-256 相符，并分别完成复算回读。页面截图：[核对页面](m3-page.png)、[报告下载](m3-download.png)。

浏览器中还实际更改了核对期间，确认旧结果与下载消失；点击“重新开始”后，两侧上传为空、期间为空、两个确认框均为 false，阶段回到 EMPTY。

重置后的最终样例流程，加载样例点击到下载点击为 **29.393 秒**，到获取下载文件为 **43.982 秒**。这是一次自动化浏览器操作实测，包含工具交互与文件获取等待；不是普通用户研究，也不是最大容量或多轮性能基准。最终计时见浏览器证据的 `timed_flow`；文件中较早流程的历史计时不作为最终流程成绩。

## 安装、配置与复现

[requirements.lock](../requirements.lock) 固定 43 包及精确 wheel 哈希，保留已有内核和测试版本。全新 `.venv-m3-clean` 使用本地 wheelhouse、`--no-index --require-hashes` 安装成功，`pip check` 通过，18 项实际配置读取检查通过；详见 [安装日志](m3-install.txt)、[wheel 哈希清单](m3-wheel-hashes.txt)。原生 wheel 针对 macOS arm64，其他平台需要另行生成并验收锁文件。

从项目目录启动，才能加载项目的 `.streamlit/config.toml`：

```sh
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

[当前配置](../.streamlit/config.toml) 绑定回环地址，上传上限 10 MiB，关闭使用统计、静态目录服务及表格内建 CSV 导出，保留 CORS/XSRF，并使用系统字体。本次通过 `lsof` 确认服务进程 PID 30133 仅监听 `127.0.0.1:8501`，这是验收时的运行状态。项目配置可以被环境变量或命令行覆盖，必须按上述本机启动方式运行，不得开放 `0.0.0.0` 或远程分享。[官方配置文档](https://docs.streamlit.io/develop/api-reference/configuration/config.toml)

上传、结果和报告使用当前会话内存，不跨会话缓存；用户下载由浏览器保存。重置释放引用，不宣称安全擦除内存、交换区或已下载文件。页面操作和恢复步骤见 [使用指南](m3-workflow.md)；内核与报告既有无文件/网络调用测试属于 API 层证据，不能替代系统网络观察。
